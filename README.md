# CineVault

CineVault is a full-stack movie management application built with React, Node.js, Express, Knex, and SQLite.

It allows users to manage movies, actors, and producers through a React frontend connected to a REST API.

## Tech Stack

### Frontend
- React
- Vite
- Redux Toolkit
- Axios
- Ant Design
- React Router

### Backend
- Node.js
- Express.js
- Knex.js
- SQLite
- JWT Authentication
- bcrypt
- Multer

## Features

- User registration and login
- JWT-based authentication
- View and search movies
- Add, edit, and delete movies
- Manage actors
- Manage producers
- Associate actors with movies
- Associate producers with movies
- Image and poster uploads
- Pagination and search
